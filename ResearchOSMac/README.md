# ResearchOS Demo

ResearchOS 把论文组织成围绕研究问题的可追溯判断，而不是另一个文件列表。

## 这版可以体验

- 空白、可持久保存的真实研究工作区
- Zotero 本地库只读连接与分类导入
- 本地 PDF 的题名、作者、DOI、摘要和全文提取
- 可用时调用 Mac 设备端模型生成待确认的论文结构卡
- 以研究问题为入口的三栏 macOS 原生界面
- 当前工作结论
- “形成共识—仍有分歧—证据空白”证据板
- 每个研究问题的一条具体下一步建议
- 待读 Inbox 与论文库
- 可搜索的结构化论文卡片
- 本地 PDF 导入入口
- 基于当前证据的演示问答

## 体验路径

1. 新建一个与你论文直接相关的研究问题。
2. 打开“Zotero”，选择现有分类并只读导入；也可以通过工具栏导入单篇 PDF。
3. 在“待读 Inbox”中选择论文，提取全文并使用设备端模型分析。
4. 检查生成的研究问题、方法、发现和限制，再标记为已整理。

## 重新构建

```shell
./scripts/build-researchos.sh
```

构建产物位于 `dist/ResearchOS.app`。

## 列表与阅读

- 写作、处理队列、论文库顶部的“列表外观”可切换紧凑或舒适密度；写作列表还可关闭正文预览。设置会在重启后保留。
- “新建或导入”集中在窗口顶部，打开文稿或原文时仍然可用。写作支持新建笔记、论文、文件夹，以及文件和文件夹导入。
- 列表隐藏后，窗口顶部仍可搜索；输入关键词会展开列表显示结果。
- “专注模式”（⇧⌘F）收起导航、列表和标签栏；再次点击可恢复进入前的布局。
- Markdown 阅读工具栏提供章节目录与阅读设置。目录来自实际渲染的标题；字号、行距和正文宽度可调整并自动记住。
- 阅读模式精简常驻操作，切换编辑后才显示格式工具栏。保存仍可使用工具栏按钮或 ⌘S。
- 论文卡片与原文合并为一个阅读标签；原文居中，摘要、方法、发现和状态从右侧“论文信息”查看或收起。
- PDF 阅读器支持 ⌘F 文内查找、跳页、缩放、适合宽度/整页，并可在缩略图与 PDF 目录之间切换。
- 标签页支持自适应宽度、拖动排序、“全部标签”菜单，以及 ⇧⌘T 重新打开刚关闭的标签页。
- 导航、标签和工具控件在 macOS 26 及更高版本使用系统 Liquid Glass；正文维持实色背景以保证长文阅读清晰。
